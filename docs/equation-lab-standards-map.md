# Equation Lab: Standards Map

Teacher reference for the Equation Lab. Each grade lists its stations ranked by how closely they match that grade's Utah Core math standards, strongest fit first. A station appears under more than one grade when it fits both.

## How to read the match labels

- Direct fit: Teaches the standard.
- Good connection: Supports the standard.
- Stretch: Above grade level.
- Pure enrichment: Mostly just wonder.

## Check the codes before you use them

Codes follow the 2016 Utah Core as shown in UEN's Online Core Resource (https://www.uen.org/core/math/) and the Utah high school standards document. The Utah State Board of Education is reviewing a revised P-12 math draft this fall, so confirm each code on uen.org before it goes into a lesson plan.

## Notes on fit

- Logarithms themselves (F.LE.4) are Secondary Math III. The folding-paper station fits Secondary Math I as exponential (doubling) growth.
- Periodic-function standards (F.TF) are Secondary Math III, so the Wave and Fourier stations are placed with 8th grade (reading graphs) and noted here for Math III.
- Normal distribution fitting (S.ID.4) is Secondary Math III. The Normal Distribution station is placed in 7th grade for the probability work it does.
- Navier-Stokes shows only one consequence of the full equations: area times speed stays constant in a pipe.
- Black-Scholes is the one-step average-payout toy version and is not investment advice.
- Calculus itself is beyond grades 7 to 9; the station uses slope as a rate of change.
